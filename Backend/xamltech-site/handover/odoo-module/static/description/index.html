🏗️ Built for Odoo 19 Enterprise & Community

  • Inherits website.layout — fully compatible with Odoo's website editor
  • Assets declared in web.assets_frontend via the manifest — no deprecated qweb key
  • No jQuery — all JS is vanilla ES5 compatible, safe for Odoo 19's stripped frontend
  • SCSS uses only standard CSS features — no @import, no @use (Odoo SCSS compiler safe)
  • RTL handled via [dir="rtl"] & nested selectors — no JavaScript direction flip
  • PWA scope fixed to / so the Service Worker intercepts all page navigations
