# POS Go Onboarding & Guided Tours

Professional interactive onboarding system for POS Go.

The system guides users through real business tasks rather than passive tooltips.

Core principle:

> One tour = one user goal.

Primary activation:

`Store configured → Product ready → POS ready → First sale`

See the documentation in this directory for product goals, UX, architecture, technical design, API, events, trial rewards, Arabic RTL, testing, implementation plan, and engineering tasks.
