# Arabic RTL Specification

## Language

Default onboarding language: `ar`

## Requirements

- RTL layout.
- Arabic typography.
- Arabic terminology.
- RTL positioning.
- RTL navigation icons.
- Responsive Arabic bubbles.

## Preferred terminology

| English | Arabic |
|---|---|
| Store | المتجر |
| Product | المنتج |
| Category | القسم |
| POS | نقطة البيع |
| Cashier | الكاشير |
| Sale | عملية البيع |
| Payment | الدفع |
| Cart | السلة |
| Inventory | المخزون |
| Customer | العميل |
| Reports | التقارير |
| Settings | الإعدادات |

Use short, practical, human Arabic rather than literal technical translation.
