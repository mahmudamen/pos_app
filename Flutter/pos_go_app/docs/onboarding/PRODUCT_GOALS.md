# Product Goals

## Business Objective

Increase the percentage of users who successfully configure and use POS Go.

## Primary Goal

Move a new user from:

`New Account → Store Created → Store Configured → Product Added → POS Ready → First Sale → Activated Customer`

## Core Goals

- Reduce time to first sale.
- Make configuration understandable.
- Teach through real actions.
- Persist progress.
- Adapt to existing business state.
- Provide Arabic-first RTL onboarding.
- Allow pause, resume, skip and close.
- Reward eligible trial users after successful onboarding.

## Core Principle

> User success is more important than tour completion.

## Activation

Primary activation:

- `sale.created`
- `payment.completed`

Secondary milestones:

- `store.configured`
- `product.created`
- `terminal.configured`
- `cash_session.opened`
