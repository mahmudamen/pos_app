Theme Features
🌙
Dark Mode Default
Deep-space dark theme with luminous accent blue. Reduces eye strain and looks stunning on modern displays.
☀️
One-Click Light Mode
Seamless toggle persisted in localStorage. Follows OS colour scheme preference automatically.
🌐
Full RTL Arabic
Every component supports right-to-left. Cairo font covers Arabic + Latin in one stack.
🎨
CSS Design Tokens
Zero hardcoded colours. All values in :root CSS variables — one-line rebranding.
📱
Fluid Responsive
CSS clamp() everywhere. Pixel-perfect from 320px to 4K. No media-query breakpoint hacks.
⚡
PWA + Service Worker
Offline-first. Web App Manifest included. Installable on mobile home screens.
🛒
Addons Store
Live search, category filter, sort, staggered animations — all vanilla JS, no jQuery.
💬
WhatsApp Integration
Floating button and contact form with pre-filled WhatsApp deep-link. No plugin needed.
🔍
SEO + JSON-LD
Organization, Service, FAQPage, ItemList structured data. AI-readable on every page.
