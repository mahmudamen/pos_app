# Reactive Bright Theme

`xt_reactive_bright_theme` is a CSS-only Odoo 19 backend and login theme.

It changes the visual system with a calmer teal/indigo palette, softer backgrounds, and cleaner cards without adding server models, security rules, or custom controllers.

Install it from Apps as **Reactive Bright Theme**. If another backend theme is installed, this module loads later through `ir.asset` records and should visually win most shared styles.
